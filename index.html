这份指南怎么用

我把单板从零到能连续转弯的路线整理了一遍，每一节都配了图，重点的地方也标好了视频时间点。不用急着一次看完，用到哪里翻到哪里就好。

有一句话可以先记住：不管是哪一种转弯，目的都是为了控速、减速和刹车。动作想不明白的时候，就回到这一句，通常就通了。

第一天的进度，大概是这样

时段内容
上午穿装备 → 平地适应 → 练起身 → 单脚滑行 → 后刃刹停 → 后刃推坡
下午后刃落叶飘 → 前刃推坡 →（有余力再碰前刃落叶飘）
第一天能做到后刃落叶飘，就已经很棒了。不用跟别人比 —— 大部分人的换刃都是第二天、第三天才慢慢出来的。

雪道分级：先看懂颜色

雪场地图和每条雪道的入口都会标颜色，代表难度：

颜色难度
🟢 绿道初级道，坡度最缓
🔵 蓝道中级道
⚫ 黑道 / 🔴 红道高级道
第一天可以安心待在绿道。如果有人说“走啦上去玩”，可以直接说还想在这边再练练 —— 新手受伤最常见的原因，就是上了还没准备好的雪道，然后一路失控往下冲。不着急，慢慢来才走得远。

口袋里记得别放硬东西

胸前口袋千万不要放硬物。摔倒的时候是胸口、肋骨直接压在那个东西上，会很疼。外套两侧口袋最好也空着。

要带的东西放裤子口袋就好。如果放手机，记得把拉链拉上，不然摔一下可能就飞出去了，雪地里很难找回来。

包里可以带上这两样

🍵小号保温杯，接点温水。累的时候喝一口真的很舒服。冷天不太会觉得渴，但其实身体脱水挺快的。
🍫一两条能量棒。有点低血糖的时候可以马上吃。饿过头会让动作整个散掉，比技术问题更需要注意。

会怕速度，是很正常的

几乎每个初学者都会怕，跟胆子大小没关系。给你两个具体的办法：

🐢从慢速开始，慢慢习惯就好。不用一上来就挑战自己能承受的极限。先在很缓的地方滑，等身体适应了这个速度，再稍微快一点点。害怕这件事，是可以被熟悉感一点点磨掉的。
👀看你要去的方向，不要看脚下。一低头看板子，重心马上就会后坐、身体也跟着僵住，反而更容易失控。把视线抬起来看远处，身体自己会稳下来。

可以让教练帮你拍一段视频

自己的感觉和实际动作，差距会大到让你意外。你以为自己站得挺直，视频里可能整个人是弓着的。

请教练帮你拍一小段，然后对照“基础概念”里那张三种站姿的图看一看。这样看一次，比闷头多练十趟还有用。
最后想说：学单板一定会摔，这真的很正常，不是你的问题。护具戴齐，慢慢来，第一天能自己滑下来就已经很厉害了。
1

基础概念

先把这些弄明白，教练说什么你就听得懂了

雪具三件套

雪板雪鞋固定器

雪板部位与前刃后刃

穿上雪板之后：脚尖那一侧是前刃，脚后跟那一侧是后刃。就这么简单。

正脚还是反脚（Regular / Goofy）

三个判断方法

  1. 让朋友从背后轻轻推你一下，先迈出去稳住自己的那只脚，就是前脚。
  2. 穿袜子在光滑地板上滑一下，自然停在前面的那只脚，就是前脚。
  3. 踢球惯用的那只脚，通常是后脚（发力的脚在后面）。
不用太纠结这个：玩过滑板、冲浪、长板的话，沿用同一个前脚就行。要是两边都觉得别扭，两边各滑几趟，身体自己会告诉你答案。

固定器角度怎么调

为什么有人说 ±15，有人说 +15/0？

其实两种都对，只是两种不同的思路，没有谁错：

设定特点
对称鸭子站姿
+15/-15、+12/-12		 两脚对称外八。正滑反滑一样顺，以后想学 switch（反着滑）、玩公园会很友好。很多雪场租赁默认给这个。
微鸭 / 偏前
+15/0 ~ +15/-6		 后脚接近正对板身。后脚更容易把力压进后刃，前刃顶胯也更顺。新手阶段反正用不到 switch，很多教练会这样给。
新手阶段这两者的差别很小，你几乎感觉不出来。所以不用自己纠结，让教练按你的身高、腿长和柔韧度设一个就好。如果之后想自己微调，一次动 3° 左右，滑两三天再决定。

滚落线（Fall Line）

把球放在坡上，它自己滚下去的那条路线，就是滚落线。教学里讲的“板头朝山下”，说的都是这条线。

为什么要知道这个：雪道常常是斜着修的，你以为的“正下方”和真正的滚落线可能差了几十度。速度忽快忽慢、转弯总是转不过来，很多时候只是因为参照错了，不是动作有问题。

卡刃（Catching an Edge）

山下那一侧的板刃突然吃进雪里，板子被卡住、人还在往前，于是整个人被甩向地面 —— 这就是卡刃，也是单板受伤最主要的原因。

这一条记住就好：后面讲换刃的时候会反复强调“一定要有一个把板放平的过程”，就是为了避开卡刃。新手立刃太早，几乎都会摔。

三种基础站姿

共同要求：三线平行同面

肩线、胯线、板中线要平行，而且在同一个纵切面上。脚踝和膝盖略弯，收腹，躯干直立（背部刚好能感觉到脊柱挺直就可以，不用刻意挺）。

站姿重心视线
平板板中线上，两腿自然站立看板头方向（前进方向）
后刃移向后刃线，身体后靠直视身体正前方
前刃移向前刃线，顶胯、肩部前倾抬头看山上
最容易出问题的不是“膝盖弯太多”，而是“折髋”。这两件事要分清楚：屈膝屈踝是对的，弯腰撅屁股才是要避开的。

膝盖和脚踝要充分弯，像准备坐下的那一瞬间；但上半身不要往前折，胸口朝着前进方向，而不是朝着地面。
两个小自检：低头如果看不到自己的脚尖，说明脚踝弯得还不够；胸口朝地、屁股翘在后面，就是折髋了。把胸抬起来，让弯曲发生在膝盖和脚踝上就好。

怎么确认重心真的移过去了

光凭感觉很容易骗自己，可以用身体的接触点来验证：

🦵前刃：小腿胫骨压住鞋舌的挤压感越强，说明重心越靠前。重心回到板中，这个挤压感就慢慢消失。
🦶后刃：小腿肚压住固定器高背板的挤压感越强，说明重心越靠后。重心回到板中，挤压感同样会释放。
小自检：做后刃动作的时候，如果完全感觉不到小腿肚被高背板顶住，那其实只是在“弯膝盖”，重心还没真的移过去 —— 板子自然也就不太听话。

弯型术语：J / C / S

J 弯直板下滑后转上山停住 C 弯完整换一次刃 S 弯连续换两次刃
2

安全与护具

这一节比技术更重要，希望你上雪之前能看一遍

护具分级

⛑️头盔，一定要戴。没有例外。记得在下巴那里扣紧，不然一摔头盔就飞了，就等于没戴。
🛡护臀和护膝，很推荐。这两处是摔倒时最常着地的地方，尾椎要是伤到了会难受很久。
🤚护腕，建议戴。单板没有雪杖，摔倒时会本能用手撑地，手腕是最容易受伤的地方。
选护腕看这一点：要选内置硬质支撑条的款式，它能限制手腕过度后仰、把冲击力分散到前臂。纯软垫的其实只是心理安慰。另外护腕要贴身戴在手套里面，戴外面容易移位。

正确的摔法：前摔和后摔不一样

这两种摔法的处理方式是相反的，分开记就好。

🔴 后摔（向后坐倒）—— 最需要注意

  1. 下巴贴住胸口。这一下是保护后脑的，比什么都重要。
  2. 双手抱在胸前，不要往后伸。手一伸出去，最容易伤到的就是手腕。
  3. 用屁股和背部大面积着地，把冲击力分散开。

🟣 前摔（向前扑倒）

  1. 用前臂和膝盖着地，不要用手掌硬撑。
  2. 顺势往前滑出去，不用急着刹住，滑行本身就在帮你卸力。
尽量不要用手掌撑地。不管前摔还是后摔，这都是最容易犯、后果也最麻烦的本能反应。护具很有用，但替代不了正确的摔倒方式。
速度快了、心里发慌，就主动坐下或跪下。可控的摔，永远好过失控的摔。坐的时候记得先屈膝把重心降低再坐，别直挺挺往后砸，不然一样会伤到尾椎。
摔倒之后第一件事：抬头看看山上。确认上面没有人正冲下来，再慢慢起身。

雪道安全与礼仪

⬇️下方的人有路权。你在上面，就有责任避让下面的人。要超过别人的话，绕开走。
🚫尽量不要停在雪道正中间。要停就停到雪道边上。
⚠️也不要停在坡凸的正下方。上面的人看不见你，这是最容易发生碰撞的位置。
🙋摔了起不来的话，先挪到雪道边上再慢慢弄，不用在原地着急。

雪板离身时要倒扣

固定器朝下，扣在雪地上。正面朝下放的雪板几乎没有摩擦力，一点点坡度就会自己滑下山，很容易撞到下面的人。这一点新手最容易忽略。

平坦光（Flat Light）：看不清雪面的日子

阴天、下雪、起雾的时候，雪面会变成一片均匀的白，起伏和坑包完全看不出来，人会莫名其妙地绊一下、摔一跤。这不是你技术退步了，是真的看不见。

🥽换浅色镜片的雪镜（黄色、粉色、透明），比深色片更容易看出雪面的层次。
🛤️跟着别人的滑行痕迹走，雪面上的沟槽能帮你判断地形。
🐢主动放慢速度，给自己留出反应时间。

什么时候该停下来休息

一直连续摔，就休息一会儿。这不是意志力问题，有可能是累了，导致动作变形，变形就更容易摔，然后更累，恶性循环。绝大多数受伤都发生在“明明很累了还要再滑一趟”的时候。

正确穿雪鞋

脚疼、脚麻、板子不跟脚，多半是这一步没弄好

  • 袜子一定要铺平整，尤其是和速干裤重叠的那一段。
  • 鞋子抽绳拉紧之后，蹬一蹬地，可以再拉紧一次。
为什么要紧：雪鞋松的话，小腿的动作传不到雪板上，只能靠脚踝硬掰，会很累，板子也不太听话。

4

正确穿固定器

顺序对了，绑起来才有用

  1. 先穿大绑带。
  2. 再穿小绑带，小绑带在鞋头脚尖处的斜上方。
  3. 穿好之后前后压一压。
小自检：轻轻一动，雪板就跟着动，不需要用很大力。如果压了很多都感受不到雪板，多半是绑带或者雪鞋还没穿紧。
5

起身与缆车

第一天最花体力、也最容易让人泄气的两件事，会了就轻松多了

怎么从雪地上站起来

第一天大部分体力都花在这上面。但起不来几乎从来都不是力气的问题，只是方法不对。

🌸 后刃起身（推荐，比较好发力）

  1. 屁股坐在雪上，先把雪板横过来，让板身垂直于滚落线。这一步最关键。
  2. 双手抓住雪板靠板头那一侧的绑带或者板刃。
  3. 脚跟往下压，让后刃卡住雪，板子就不会往下溜了。
  4. 上半身像划船一样往膝盖方向靠近，身体尽量贴近雪板。
  5. 然后一口气起身。

🌿 前刃起身

  1. 翻身趴过来，脸朝山上。
  2. 双膝跪在雪上，让前刃卡住雪。
  3. 手撑自己的膝盖（不是撑雪地），然后把身体推起来。
力气小也能起来的关键：起不来通常是这两个原因 —— 没把板横过来（板子一直在往下溜，你等于在跟重力较劲），或者上半身离板太远（杠杆太长，相当于要把自己整个举起来）。身体越贴近雪板，越省力。
不用在陡的地方硬撑。起不来的话，先用手把自己挪到坡度缓一点的位置再起身就好，很多老手也这么做。

上魔毯

  • 初学阶段一般是抱着板或者单脚穿板上去，看雪场的规定。
  • 顺着魔毯前进的方向站好，身体微微前倾，抵消脚下突然出现的那股推力。
  • 单脚上板的话，后脚踩在板上靠近后固定器的位置。

上缆车

  1. 解开后脚，只留前脚在板上。到指定位置站好，板头朝前。
  2. 回头看一眼椅子过来，坐下就好，不用跳。
  3. 坐稳之后把安全杆放下来。
  4. 后脚踩在板上（踩在前固定器后面那块防滑垫上），别让雪板一直悬空晃，晃久了前脚会很酸。

下缆车 —— 新手最容易摔的地方

  1. 快到出口时先抬起安全杆，把板头对准正前方，前脚踩实雪板。
  2. 屁股不用急着离开椅子，等雪面托住雪板了再站起来。
  3. 站起来之后不要转身、也不要立刻停，就直板往前滑出去。
  4. 滑到旁边再停下、再坐下穿板。
先给你打个预防针：第一次下缆车摔了真的太正常了，很多滑了很久的人也会。摔了就赶紧往旁边挪一下，因为后面的椅子马上就到了。就这样而已，一点都不丢脸。
6

入门动作路线

能连续 S 弯就算入门啦，按顺序慢慢来就好

标准顺序

1后刃推坡2后刃落叶飘3前刃推坡 4前刃落叶飘5后刃 J 弯6前刃 J 弯 7前转后 C 弯8后转前 C 弯9S 弯
每个教练的顺序可能不太一样。有的会先教单脚滑行和直滑降，有的先从推坡落叶飘建立雪感再回头补。顺序不是唯一标准，跟着你教练的节奏走就好，这里只是给你自己对照进度用的。

平地适应 （上坡之前先做一下）

双脚绑好板，在平地上先让身体认识一下这块板。很多人跳过这步直接上坡，结果推坡的时候一直找不到刃在哪里。

  1. 左右摇晃。脚尖压下去，感受前刃立起来；脚跟压下去，感受后刃立起来。来回慢慢晃，体会“脚踝一动，板就动”。
  2. 蹲一蹲。屈膝屈踝往下蹲，再站起来，感受重心高低的变化。
  3. 原地跳一跳。让身体习惯脚上绑着一块板的重量和惯性。
  4. 原地转一转。试着用脚和身体，把板子在原地挪动一点角度。
为什么值得花这几分钟：这是你的身体第一次理解“我的脚踝和这块板是连在一起的”。在平地上找到这个感觉，是零风险的；等到了坡上再找，就要一边怕一边找了。

单脚蹬地滑行

  • 重心全程在前脚，包括蹬地的那一下。不然后脚一落地就把板刹停了，蹬不出加速。
  • 前脚要均匀踩板。只压前脚掌或只压后脚跟的话，板头就会一左一右乱跑。
  • 后脚踩回板上的时候，放在后固定器前方。
提醒一下：“重心在前脚”这句只适用于单脚滑行。双脚上板之后，前后脚要均匀受力，不是一直死压前脚。很多人把这句带进了推坡和落叶飘，结果后刃怎么都压不住。

后刃刹停 （最值得先学会的一招）

在学任何转弯之前，先学会怎么让自己停下来。这会是你在雪道上最踏实的安全感。

  1. 让雪板横过来，垂直于滚落线。
  2. 脚跟压下去，把后刃吃进雪里。
  3. 膝盖保持弯曲，重心压低，板子就会停住了。
记住这个组合就好：板横过来 + 脚跟压下去 = 刹车。只要知道自己随时能停下来，在坡上的恐惧会少掉一大半。后面的落叶飘、J 弯，收尾用的也都是这一招。

直滑降（放直板）

  • 板头正对山下，整块板贴雪不用刃，重心在前脚。
  • 找一个平缓的短坡；没有的话，可以用落叶飘滑到接近平地的地方，确认前方没人，再放直板下去，等板子自然停。
  • 慢慢增加放直板的时间，一点点习惯速度。
一个参考目标：待你以后能在稍陡一点的坡上放直板 3~5 秒还很从容，再学换刃会轻松很多。
控制不住方向？通常是速度超过了你能接受的范围 —— 一害怕重心就后移，一后坐就控制不了方向了。这时候提醒自己重心前移，或者干脆把速度再放慢一点。

推坡（Side Slip）

后刃推坡

  1. 准备：弯曲脚踝和膝盖，微抬脚尖，坐进高背板，找到能让雪板停住的那个平衡点。
  2. 移动：重心从后刃线慢慢往板中线移动（不要超过板中线），脚尖慢慢放下，雪板就开始缓缓下滑。
  3. 停止：重心慢慢回到后刃线，微抬脚尖，雪板慢慢停住。

前刃推坡

原理一样，改成膝盖顶向前刃、顶胯、抬起脚跟，去感受胫骨压着鞋舌的那种支撑感。

这个阶段，手自然垂在身体两侧就好，尽量别乱挥。手一乱动会直接干扰平衡。可以反复练不同的幅度，感受重心移动多少会带来多少速度变化和刹车效果。

斜滑降 + 落叶飘

落叶飘 = 推坡 + 方向控制，像一片叶子左右飘着往下落，名字很好听。

视线就是方向盘：看哪边就往哪边走，可以用手指一下方向来引导自己。后刃的时候看身体正前方，前刃的时候抬头看山上。最常见的小毛病是低头看脚下。
前刃做不出来，真的不是你的问题。前刃是背对着山下、看不见下面的，几乎所有人都会本能地抗拒，表现出来就是“前刃怎么都立不起来”。

可以这样做：先在雪道边上扶着朋友的手，或者扶着护网做前刃推坡，让身体先相信“背对山下也不会失控”。有了这份信任感之后再放手，会顺很多。

进阶目标

能比较自如地控制飘的角度和速度，横切整条雪道，而不是只能左右小幅度地挪动。

Garland 波浪练习 （很推荐加练）

这是前刃恐惧和不敢放平板的最好解药。它让你在完全不用换刃的前提下，反复体验“把板放平一点点、朝山下走一小段”的感觉。

  1. 从落叶飘开始，保持在同一个刃上。
  2. 把板稍微放平一点，让板头朝滚落线转一点点，速度会稍微起来。
  3. 马上立回原来那个刃收住，速度就降下来了。

重复这个“放平一点 → 收回来”的动作，轨迹就像一串小波浪。

为什么特别推荐这一步：换刃做不出来，最大的原因就是不敢把板放平。Garland 让你在随时都能收住的安全感里去练放平，练熟了再学 C 弯，会少摔很多次。

J 弯

  1. 放直板下滑。
  2. 转动前腿、改变膝盖指的方向，带动雪板转向。
  3. 立刃转上山，速度自然就没了，停住。
把前脚当成摇杆：想象前脚是一个游戏手柄的摇杆，想往哪边转就往哪边转前脚，后脚自然跟着走，雪板就会自己 twist 过来。
控速很简单：直板滑行的时间越短，进弯的速度就越慢。心里发怵的话，就早一点开始转。

C 弯：第一次换刃

三字口诀：看 → 压 → 转

  1. 看：先把视线看向你要去的方向。
  2. 压：重心压向前脚。
  3. 转：用胯带动身体旋转，顺序是转头 → 转肩 → 转髋 → 转脚，板子会跟着走。
手的位置从这里开始要变一下。前面推坡、落叶飘的时候手是自然垂在两侧的；开始学换刃之后，改成前手轻轻搭在前侧胯骨上，这样可以避免上半身抢着转 —— 具体原因在“换刃陷阱”那一节。

拆成三步来练

  1. 起点：用 A 刃（比如后刃）斜滑降。
  2. 中间：把板放平，让板头转向滚落线、朝着山下走。
  3. 收弯：换成另一个刃（前刃）做 J 弯收住。
C 弯和 J 弯最大的区别就在这里：J 弯是转上山、回到原来那个刃；C 弯是换到另一个刃。所以 C 弯结束的时候，你踩的一定是和起点不同的那个刃 —— 如果结束时还踩着出发那个刃，那其实做的是 J 弯，还没有真的换刃。
最关键的是时机：板头指向山下、整块板完全贴平雪面之后，耐心等大约 1 秒，再把压力转移到新刃上。太早的话很容易卡刃摔倒。
膝盖全程保持弯曲。膝盖既是发动机也是避震器。换刃之后双腿抖得厉害、在坡上突突突打滑的话，先看看是不是膝盖太直了。
关于节奏：做完一次换刃可以慢下来，先稳住速度和站姿，再做下一个。转弯的过程完全可以是慢慢的 —— 坡度缓，就会有足够的时间。

S 弯：连续换两次刃

S 弯其实就是两个方向相反的 C 弯接起来。

  1. 做完第一个 C 弯，这时你踩在 B 刃上，继续斜滑降。
  2. 斜滑降的过程要减速到自己能控制，站姿稳住了，再继续下一步。
  3. 再把板放平朝滚落线，换回 A 刃收弯 —— 第二次换刃就完成了。

把中间的推坡时间和直板时间慢慢缩短，两个反向的 C 弯就连成了流畅的 S 弯。

练习建议：在缓坡上设两个间距十米左右的参照物，保证每次换刃都完整、流畅地做完，慢慢建立肌肉记忆。不用贪大弯。

练习要点

做推坡、斜滑降和落叶飘的时候，记得这几条

  1. 不要盯着板子看，看你要去的方向，可以用手指一下方向引导自己。
  2. 不要低头。斜滑的过程中想停下来：后刃就看身体正前方，前刃就看山上。
  3. 速度快了、心里发慌，就屁股坐下或者跪下，没关系的。
  4. 先把前面的动作做熟、做稳，再开始学换刃，不然屁股会比较辛苦。
尽量不要用手掌撑地。摔倒时用手肘是可以的，手掌撑地最容易伤到手腕。

手到底该放哪？

两个阶段不太一样，别混在一起：

阶段手的位置
推坡 / 落叶飘 自然垂在身体两侧，尽量别乱挥，乱挥会干扰平衡。
开始学换刃之后 前手轻轻搭在前侧胯骨上，后手自然下垂。用来提醒上半身别抢转。
8

换刃三大陷阱

换不过去、老是摔，基本都逃不出这三条

① 上半身乱扭

现象习惯先转肩膀，但板头还朝着山下，结果越转越快、直接失控。
怎么解绅士姿势：前手轻轻搭在前侧胯骨上，后手自然下垂。整个转弯过程手别离开胯 —— 手一动，就说明上半身在抢转了。

② 换刃太快

现象雪板还没完全放平就急着压新刃，很容易卡刃摔跤。
怎么解耐心等直板滑行大约 1 秒，确认板面完全贴平雪面之后，再转移重心。

③ 重心后坐躲刃

现象害怕摔倒所以身体后仰，重心落在后脚，雪板就没办法有效入刃。
怎么解保持前驱入弯的姿态，重心稍微靠前，小腿主动压向鞋舌，板头的抓地力会明显变好。

女生实用贴士

这些都是很实际的小事，有些甚至比技术还影响体验

装备：可以直接找教练帮忙

选雪鞋、调固定器角度，直接让教练帮你就好啦。

🛷选板选鞋。跟教练说是初学者，通常会给你比较软的鞋。体重轻的女生尤其适合软板软鞋。板太硬的话压不动、转不过来，会一整天都很挫败。
📐固定器角度。让教练帮你设好。
雪鞋记得穿女款。女款的鞋楦更窄、小腿围也更细。穿男款的话小腿绑不紧，力就传不到板上 —— 这其实是很多女生“怎么都控制不了板”的真正原因，不是技术问题。

雪镜起雾

看不见会直接把恐惧放大，所以这条比想象中重要。

  • 别把雪镜推到额头上，头顶的汗气会直接糊住内层。
  • 不要用手或纸巾擦内层镀膜，擦一次就花了，之后会一直起雾。
  • 休息的时候把雪镜摘下来朝上放通风，进室内也提前摘掉。把雪镜卡在头盔上进室内，很容易起雾。

可以随身带这几样

💄润唇膏。雪场又干又冷又晒，嘴唇裂了会很难受。放口袋里随时补，选带防晒的更好。
🧴防晒霜 SPF50。雪地的紫外线反射很强，阴天也一样会晒伤。脸和脖子都要涂，雪镜边缘露出来的那一圈最容易留印子。
🩹肌肉酸痛贴 / 酸痛膏药。晚上回去贴一下大腿前侧、小腿和肩颈，第二天会舒服很多。如果第二天还想滑，这个几乎是必备的。
🧤备用手套。手套湿了会比不戴还冷，而且一整天都缓不过来。方便的话带一副替换的。

上厕所

  • 连体裤、背带裤穿脱比较费劲，提前留点时间，别等到最后一刻。
  • 水要多喝，但别憋 —— 冷天憋着真的很难受，也会让人没办法专心。

生理期

是可以滑的，注意保暖就好，但也别硬撑，累了就休息。贴暖宝宝的时候避开尾椎护具的位置，不然护臀压着它反而不舒服。状态不好就少滑两趟，真的没什么大不了。

第一天酸痛是正常的

大腿前侧、小腿、脖子、尾椎酸，都是正常的，不代表你姿势错了。这些肌肉平时基本用不到。晚上用热水好好泡一下，贴个酸痛贴，第二天会好很多。
