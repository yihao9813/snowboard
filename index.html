1基础概念

上雪前先把这些搞明白，教练说什么你就听得懂

雪具三件套

雪板雪鞋固定器

雪板部位与前刃后刃

穿上雪板后：脚尖方向 = 前刃，脚后跟方向 = 后刃。

正脚还是反脚（Regular / Goofy）

三个判断方法

  1. 让朋友从背后轻推你一下，先迈出去救场的那只脚，就是前脚。
  2. 穿袜子在光滑地板上滑一下，自然停在前面的那只脚，就是前脚。
  3. 踢球惯用的那只脚，通常是后脚（发力脚在后）。
不用纠结：玩过滑板、冲浪、长板的，直接沿用同一个前脚就行。真的两边都别扭，两边各滑几趟再定。

固定器角度怎么调

新手推荐 前脚 +15°、后脚 0° 或 -6°：容错高，正滑反滑都好平衡，膝盖压力也小。

别照抄别人：角度跟身体柔韧度和滑行风格强相关。真要调，一次只动 3° 左右，滑两三天再决定要不要继续改。

滚落线（Fall Line）

把球放在坡上，它自己滚下去的那条路线就是滚落线。所有教学里讲的「板头朝山下」，指的都是这条线。

为什么重要：雪道常常是斜着修的，你以为的「正下方」和真正的滚落线可能差几十度。速度忽快忽慢、转弯总是转不过来，很多时候是因为参照错了。

卡刃（Catching an Edge）

山下侧的板刃突然吃进雪里，板子被卡住而人还在往前，于是被狠狠甩向地面 —— 这就是卡刃，单板受伤最主要的原因。

记住这一条：后面讲换刃时反复强调的「一定要有一个把板放平的过程」，就是为了避免卡刃。新手立刃过早，几乎必摔。

三种基础站姿

共同要求：三线平行同面

肩线、胯线、板中线要平行，且在同一个纵切面上。脚踝与膝盖略弯，收腹，躯干直立（背部刚好能感到脊柱挺直即可，不要过挺）。

三种站姿的差别

站姿重心视线
平板板中线上，两腿自然站立看板头方向（前进方向）
后刃移向后刃线，身体后靠直视身体正前方
前刃移向前刃线，顶胯、肩部前倾抬头看山上
最常犯的错：哈腰、撅屁股、膝盖弯太大。膝盖弯过头必然导致哈腰撅屁股，速度就控制不住了。膝盖只要微弯。

怎么确认重心真的移过去了

光靠感觉很容易骗自己，用身体接触点来验证：

🦵前刃：小腿胫骨压住鞋舌的挤压感越强，说明重心越靠前。重心回到板中，这个挤压感就逐渐释放。
🦶后刃：小腿肚压住固定器高背板的挤压感越强，说明重心越靠后。重心回到板中，挤压感同样逐渐释放。
自检：如果做后刃动作时完全感觉不到小腿肚被高背板顶住，那你只是在「弯膝盖」，重心根本没移过去，板子自然不会听你的。

弯型术语：J / C / S

J 弯直板下滑后转上山停住 C 弯完整换一次刃 S 弯连续换两次刃

单板的底层逻辑

不管是什么转弯，它的目的都是为了控速、减速和刹车。想不明白动作的时候，就回到这一句。

2安全与护具

这一节比任何技术都重要，先看完再上雪

护具分级

⛑️头盔 = 所有人必戴。没有例外。一定要在下巴处扣紧，否则一摔头盔就飞了，等于没戴。
🍑护臀 + 护膝 = 新手强烈推荐。这两处是摔倒时最常着地的部位，尾椎伤了很难受很久。
🤚护腕 = 单板新手建议戴。单板没有雪杖，摔倒时本能用手撑地，手腕是高发受伤点。
选护腕看这一点：要选内置硬质支撑条的款式，能限制手腕过度后仰、把冲击力分散到前臂。纯软垫的只是心理安慰。另外护腕要贴身戴在手套里面，戴在外面容易移位。

正确的摔法

  1. 感觉要摔了，主动团身，别硬撑。
  2. 尽量侧身滚倒，让屁股或背部先着地。
  3. 手臂收在身前，用前臂或手肘卸力。
绝不用手掌撑地。这是新手最容易犯、后果最严重的本能反应。护具替代不了正确的摔倒技巧。
速度快了就主动坐下或跪下。可控的摔，永远好过失控的摔。

雪板离身时必须倒扣

固定器朝下，扣在雪地上。正面朝下放的雪板摩擦力极小，一点点坡度就会自己加速滑下山，像导弹一样冲向下面的人。这是新手最容易犯的危险错误。

3正确穿雪鞋

脚疼、脚麻、板子不跟脚，八成是这一步没做好

  • 袜子一定要平整，尤其是和速干裤相覆盖的部分。
  • 鞋子抽绳拉紧后，蹬一蹬地，可以再拉紧一次。
为什么要紧：雪鞋松的话，小腿的动作传不到雪板上，只能靠脚踝硬掰，会非常累而且控制不住板。

4正确穿固定器

顺序错了，绑多紧都没用

  1. 先穿大绑带。
  2. 再穿小绑带，小绑带在鞋头脚尖处的斜上方。
  3. 穿好后前后压一压。
自检：轻轻一动，雪板就跟着动，不需要很大力。如果压很多都感受不到雪板，大概率是绑带或者雪鞋没穿紧。

5入门九个动作的完整路线

练到能连续 S 弯，基本就算入门了

标准顺序

1后刃推坡2后刃落叶飘3前刃推坡 4前刃落叶飘5后刃 J 弯6前刃 J 弯 7前转后 C 弯8后转前 C 弯9S 弯
个别教练可能练习顺序不一样。有的会先教单脚滑行和直滑降，有的先从推坡落叶飘建立雪感再回头补。顺序不是唯一标准，跟着你教练的节奏走就好，这里的顺序供你自己对照进度用。

① 单脚蹬地滑行

  • 重心全程在前脚，包括蹬地那一下。否则后脚一落地就把板刹停了，蹬不出加速。
  • 前脚要均匀踩板。只压前脚掌或只压后脚跟，板头就会一左一右乱跑。
  • 后脚踩回板上时，放在后固定器前方。

② 直滑降（放直板）

  • 板头正对山下，整块板贴雪不用刃，重心在前脚。
  • 找一个平缓短坡；没有的话，用落叶飘滑到接近平地处、确认前方无人，再放直板下去，等板子自然停。
  • 逐渐增加放直板的时间以克服对速度的恐惧。
目标：能在中级道放直板 3~5 秒还比较从容，再开始学换刃，会游刃有余得多。
控制不住方向？通常是速度超过了你能接受的范围，一害怕重心就后移，一后坐就控制不了前进方向。提醒自己重心前移，或者把速度再放慢一点。

③ 推坡（Side Slip）

后刃推坡

  1. 准备：弯曲脚踝和膝盖，微抬脚尖，坐进高背板，找到能让雪板停住的平衡点。
  2. 移动：重心从后刃线慢慢往板中线移动（不要超过板中线），脚尖慢慢放下，雪板开始缓慢下滑。
  3. 停止：重心慢慢回到后刃线，微抬脚尖，雪板慢慢停住。

前刃推坡

原理相同，改为膝盖顶向前刃、顶胯、抬起脚跟，去感受胫骨压鞋舌的支撑。

手臂放低，放在身体两侧，不要乱动，乱挥手会直接干扰平衡。反复练不同幅度，感受重心移动幅度带来的速度变化和刹车效果。

④ 斜滑降 + 落叶飘

落叶飘 = 推坡 + 方向控制，像一片叶子左右飘着往下落。

视线就是方向盘：看哪边就往哪边走，可以用手指方向引导。后刃时看身体正前方，前刃时抬头看山上。最常见的错误是低头看脚下。

进阶目标

能精准控制飘的角度和速度，游刃有余地横切整条雪道，而不是只能左右小幅度挪动。

⑤⑥ J 弯

  1. 放直板下滑。
  2. 转动前腿、改变膝盖指向，带动雪板转向。
  3. 立刃转上山，速度自然消失，停住。
前脚当摇杆：把前脚想象成一个游戏手柄的摇杆，想往哪边转就往哪边转前脚，后脚自然跟随，这时雪板会自己 twist 过来。
控速很简单：直板滑行的时间越短，进弯速度就越慢。怕了就早点开始转。

⑦⑧ C 弯：第一次换刃

三字口诀：看 → 压 → 转

  1. 看：先把视线看向你要去的目标方向。
  2. 压：重心压向前脚。
  3. 转：用胯带动身体旋转，顺序是转头 → 转肩 → 转髋 → 转脚，板子跟着走。双手放在身前，随目光转动。

拆解成两步来练

  1. 斜滑降。
  2. 放直板，接一个 J 弯。
最关键的时机：板头指向山下、整块板完全贴平雪面之后，耐心等约 1 秒，再把压力转移到新刃上。早了必定卡刃摔倒。
全程弯曲膝盖。膝盖既是发动机也是避震器。换刃后双腿抖得厉害、在坡上突突突打滑，先检查是不是膝盖太直了。
节奏：做了一次换刃可以慢下来，先稳住速度和站姿，再做下一个。转弯过程可以是缓慢的 —— 坡度缓，就会有足够的时间。

⑨ S 弯：连续换两次刃

  1. C 弯后继续斜滑降。
  2. 斜滑降过程要减速到能控制，才继续做下一步。
  3. 放直板，接一个 J 弯。

把中间的推坡时间和直板时间逐渐缩短，两个反向的 C 弯就连成了流畅的 S 弯。

练习建议：在缓坡上设两个间距约 10 米的参照物，确保每次换刃都完整、流畅地完成，逐步建立肌肉记忆。别贪大弯。

6练习要点

做推坡、斜滑降和落叶飘时，记住这几条

  1. 不要盯着板子看，看你要去往的方向，可以用手指方向引导。
  2. 不要低头。斜滑过程中想停下来：后刃就看身体正前方，前刃就看山上。
  3. 速度快了、感觉怕了，就屁股坐下或者跪下。
  4. 要先把前面的动作做熟练、做稳，才开始学换刃，不然要摔屁股的。
千万不要用手掌撑地。摔倒时用手肘是 OK 的，手掌撑地最容易伤手腕。

7换刃三大陷阱

换不过去、老是摔，基本逃不出这三条

陷阱现象破解
上半身乱扭 习惯先转肩膀，但板头还朝着山下，结果越转越快、直接失控。 绅士姿势：前手抱胯，强制上半身稳定，改用下半身带动雪板转向。
换刃过快 雪板还没完全放平就急着压新刃，极易卡刃摔跤。 耐心等直板滑行约 1 秒，确认板面完全贴平雪面后，再转移重心。
重心后坐躲刃 害怕摔倒导致身体后仰，重心落在后脚，雪板无法有效入刃。 保持前驱入弯姿态，重心略靠前，小腿主动压向鞋舌，增强板头抓地力。
